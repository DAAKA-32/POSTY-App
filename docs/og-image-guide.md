# Guide de Création - Open Graph Image POSTY

## 📐 Spécifications Techniques

- **Taille recommandée**: 1200×630px (ratio 1.91:1)
- **Format**: PNG ou JPG
- **Poids max**: < 300KB
- **Nom du fichier**: `og-image.png`
- **Emplacement**: `/public/og-image.png`

## 🎨 Éléments à Inclure

### Obligatoire
1. **Logo POSTY** - En haut à gauche ou centré
2. **Slogan principal**: "Générateur de Posts LinkedIn IA"
3. **Fond professionnel** - Couleurs brand POSTY

### Optionnel (mais recommandé)
4. **Screenshot de l'interface** - Aperçu de l'app
5. **Badge/Tag**: "Essai Gratuit 7 Jours"
6. **Icônes LinkedIn/IA** - Visuels subtils

## 🎯 Bonnes Pratiques

- **Zone de sécurité**: Gardez 40px de marge sur tous les côtés
- **Texte lisible**: Taille min 40px, police sans-serif
- **Contraste élevé**: Texte foncé sur fond clair ou inversement
- **Pas trop de texte**: Maximum 6-8 mots

## 🛠️ Outils Recommandés

### Canva (Gratuit)
1. Aller sur canva.com
2. Chercher "Open Graph Template"
3. Dimensions personnalisées: 1200×630px
4. Utiliser les templates ou créer from scratch

### Figma (Gratuit)
1. Créer un frame 1200×630px
2. Importer le logo POSTY
3. Ajouter texte et éléments visuels

### Photoshop/Photopea (Avancé)
1. Nouveau document 1200×630px, 72 DPI
2. Design custom

## ✅ Checklist Avant Export

- [ ] Dimensions exactes 1200×630px
- [ ] Logo POSTY visible et net
- [ ] Slogan lisible même en petit
- [ ] Fond professionnel (pas de blanc pur)
- [ ] Contraste suffisant
- [ ] Poids < 300KB
- [ ] Format PNG ou JPG
- [ ] Nom: `og-image.png`

## 📍 Installation

Une fois créée, placer l'image:
```
/public/og-image.png
```

L'image sera automatiquement utilisée pour:
- Partages LinkedIn
- Partages Twitter
- Partages Facebook
- Aperçus Slack/Discord
